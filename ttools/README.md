# టీచర్ టూల్స్ (ttools/)

ఈ ఫోల్డర్‌లో పెట్టిన ప్రతి `.html` ఫైల్ యాప్‌లో **టీచర్ ప్యానెల్ → 📚 పుస్తకాలు / టూల్స్ → 🧑‍🏫 టీచర్ టూల్స్** లో ఆటోగా కనిపిస్తుంది (విద్యార్థులకు కనిపించదు).

- ఫైల్ పేరు అర్థమయ్యేలా పెట్టండి (ఉదా: `MDM_Akshayapatra_Voucher_RagiJava_Chikki_Egg.html`).
- GitHub వెబ్‌లో ఈ ఫోల్డర్ తెరిచి **Add file → Upload files** తో మీరే చేర్చవచ్చు.
- యాప్‌లో 🔄 నొక్కితే కొత్త ఫైళ్లు వెంటనే వస్తాయి.
- విద్యార్థుల వ్యక్తిగత డేటా ఉన్న ఫైళ్లు ఇక్కడ పెట్టకూడదు (ఈ repo పబ్లిక్).
