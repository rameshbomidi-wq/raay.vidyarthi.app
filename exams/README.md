# 📝 పరీక్ష జవాబులు (FA / SA)

ఈ ఫోల్డర్‌లో HTML జవాబుల టూల్ పెడితే చాలు. రాయ్ విద్యార్థి యాప్ **టెస్ట్** ట్యాబ్‌లో ఆ తరగతి పిల్లలకు ఆటోమేటిక్‌గా కనిపిస్తుంది. కోడ్ ఏమీ మార్చనవసరం లేదు.

## ఎలా పెట్టాలి (GitHub వెబ్‌సైట్‌లో)
1. ఈ `exams` ఫోల్డర్ తెరవండి → **Add file → Upload files**
2. HTML ఫైల్ ఎంచుకోండి → కింద **Commit changes** నొక్కండి
3. 1–2 నిమిషాల తర్వాత యాప్‌లో టెస్ట్ ట్యాబ్ → 📝 పరీక్ష జవాబులు → 🔄 నొక్కండి

## ఫైల్ పేరు నియమం (తప్పనిసరి)
`Class<తరగతి>_<సబ్జెక్టు>_<పరీక్ష>_<మిగతాది ఏదైనా>.html`

- తరగతి: `Class1` … `Class10`
- సబ్జెక్టు (English లో): `Telugu`, `English`, `Maths`, `EVS`, `Hindi`, `Science`, `Physics`, `Biology`, `Social`
- పరీక్ష: `FA1`, `FA2`, `FA3`, `FA4`, `SA1`, `SA2`

ఉదాహరణలు:
- `Class3_Telugu_SA1_Model_Paper_2026-27_Answers.html`
