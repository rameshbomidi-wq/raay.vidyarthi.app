# ⭐ రాయ్ స్పెషల్ SSC – పుస్తకాలు (ssc/books/)

ఈ ఫోల్డర్‌లో పెట్టిన ప్రతి **PDF** (లేదా `.html`) ఫైల్ యాప్‌లో **నేర్చుకో → ⭐ రాయ్ స్పెషల్ SSC 2027 → 📚 Mission March పుస్తకాలు** లో ఆటోగా కనిపిస్తుంది (10వ తరగతి విద్యార్థులకు).

## ఎలా అప్‌లోడ్ చేయాలి
1. GitHub లో ఈ ఫోల్డర్ (`ssc/books`) తెరవండి.
2. **Add file → Upload files** → PDF ఎంచుకుని **Commit changes** నొక్కండి.
3. 2–3 నిమిషాల తర్వాత యాప్‌లో 🔄 నొక్కితే పుస్తకం కనిపిస్తుంది.

## ఫైల్ పేరు
- English లో, ఖాళీలు లేకుండా `_` తో: ఉదా `Mission_March_Maths_Final.pdf`, `Mission_March_Physics_Final.pdf`, `Mission_March_Social_Final.pdf`.
- పేరులో Maths / Physics / Biology / Social / English / Hindi / Telugu ఉంటే ఆ సబ్జెక్టు గుర్తు ఆటోగా వస్తుంది.

## పరిమితి
- GitHub వెబ్ అప్‌లోడ్ ఒక్క ఫైల్‌కు **25 MB** వరకే. పెద్ద PDF అయితే ముందు కుదించండి (ఉదా: ilovepdf.com → Compress) లేదా Claude కు పంపండి.
- విద్యార్థుల వ్యక్తిగత వివరాలు ఉన్న ఫైళ్లు పెట్టకూడదు (repo పబ్లిక్).
